# 🎲 Checkers Game

A modern, clean, and responsive version of the classic **Checkers Game**, built to be played directly in your web browser. This project features single-player gameplay against an AI and a local pass-and-play mode for friends.


---

## ✨ Features

- **👥 Game Modes:**
  - `Play` (Jogar): Solo match against the computer.
  - `Play with a friend` (Jogar com amigo): Local multiplayer mode (pass-and-play).
- **🤖 Difficulty Levels:**
  - 🟢 Easy (Fácil)
  - 🟡 Medium (Médio)
  - 🔴 Hard (Difícil)
- **⚙️ Custom Settings:**
  - 🌐 Multi-language support.
  - 🔊 Sound effects control (On/Off).
- **🔄 Game Flow Management:**
  - Intuitive main menu, game reset option (`New game`), and a confirmation prompt to prevent accidental exits.

---

## 🛠️ Technologies Used

The project was built using standard web technologies without external dependencies:

- **HTML5:** Screen structure, main menus, and the game board canvas.
- **CSS3:** Modern styling, responsive layout, and piece movement animations.
- **JavaScript (ES6):** Core game logic, move validation (checkers rules), and the AI algorithms for each difficulty level.

## 🚀 Running the Project Locally

To test or modify the game on your own machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project folder:**
   ```bash
   cd checkers
   ```

3. **Launch the game:**
   Simply double-click the `index.html` file to open it directly in your preferred web browser.

---

## 📋 Rules Implemented

The game implements the traditional rules of checkers:
- Standard forward diagonal movements.
- Mandatory captures whenever a jump is available.
- "King" promotion upon reaching the opponent's back row, unlocking backward and multi-tile movement.
